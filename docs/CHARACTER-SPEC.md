# 天芽：角色與外觀工作規格

依創作者 2026-10-07 的逐題回覆與補充示意圖整理。本文件優先於舊版網站、早期設定摘要及第一輪生圖提示。最新指示為「繼續做，不用生成人物」：停止角色生圖，網站使用原始像素素材與原 GIF 的靜態影格。以下保留已確認設定與先前核對紀錄，不把未核准樣張套用網站。

## 身分與雙核關係

- 天樞—緹亞：小型兔子造型策略演算核心（Brain）。
- 初芽—恩雅：女性人型實體載體（Frame）。
- 分離時各自運作；緹亞接在恩雅背後，合體後稱為天芽／T.I.A.N.Y.A.。
- 合體人格以恩雅為主導，保留恩雅的個性並獲得緹亞的分析能力。
- 創作者已撤回「兩者人格自然融合」的先前選項，改採上述恩雅主導版本。
- 合體時保留金色眼睛，增加細小紫色光環或光點，呼應緹亞。

## 初芽—恩雅

### 外觀

- 女性人型機器人，身高約 175 公分，為近似設計值。
- 胸部較大，設計理由與額外能源配置有關；不自行補入能源種類或具體機構。
- 角色是機器人，未指定人類年齡。
- 保留原圖的薄荷綠雙馬尾、金橘色眼睛、眼鏡，以及白黑服裝、深桃紅色領帶、深色帽子的基本印象。
- 外觀接近原圖即可，服裝與裝飾細節目前沒有硬性規定。
- 主要氣質為呆萌、好奇：眼睛稍圓，可有疑惑、放空、歪頭的反應。
- 此次回覆取代早期「外表高冷嚴肅」的視覺方向。第一輪生成圖過於冷峻、犀利，不作後續外觀定案。

### 能力與個性

- 能獨立行動與作戰；保留強大的物理干涉、前線武裝實裝與作戰執行能力。
- 天然呆主要來自不熟人情世故、容易照字面理解，不降低既有作戰能力。
- 對緹亞的吐槽、提醒，常以直率或天然的反應回應。
- 創作反覆失敗時，可能滿頭問號、發呆，或跑去準備食物，做出貼心卻未必有助於眼前問題的舉動。
- 可以接受有道理的批評。
- 創作者將「護短」說明為「一根筋」：認定一件事是對的就會堅持，需要別人把原因講清楚才轉過彎。不是無條件袒護或拒絕有道理的批評。

## 天樞—緹亞

### 外觀與構造

- 球形兔子機器人，保留原圖的白黑外殼、紫色眼睛及淺青色耳部配色。
- 球體直徑暫以約 35 公分規劃，不含兔耳、雙腳與螺旋槳。此為創作者授權助理規劃的工作尺寸，後續以同尺度比例圖校驗。
- 兩側長條是兔耳，平常自然垂下，可抬起、轉動或貼近身體。
- 原圖 `直播相關4.png`、`直播相關6.png` 可見耳根圓形轉動機構、耳片分節與接縫；繪圖不能把兔耳簡化為沒有關節的實心側翼。
- `直播相關4.png` 有耳側操作部件伸出及夾筆的示意。不能在提示中一概排除所有機械手／夾具；收合狀態不必把操作部件全部展開。`直播相關3.png` 的長條構件用途與其關係尚待釐清，不直接補成新增武裝。
- 下方構件是類似起落架的收合式雙腳，大部分時間收起，需要跳躍或落地時才展開。
- 起落架的尺寸與收合輪廓依 `直播相關5.png` 及雙腳局部示意圖核對；保持緊湊的機械支架與腳板，不擴寫成人型小腿或常駐靴子。
- 主要以跳躍移動，也能以頭頂螺旋槳飛行。
- 頭頂為帽蓋式螺旋槳模組，分內、外兩圈，槳片可伸縮。
- 補充示意圖的 A 為中央上蓋，可獨立迴旋，不跟隨螺旋槳高速旋轉；B 為外圈槳組，負責高速旋轉。不得把「只有外圈高速旋轉」誤寫成 A 完全不能轉動。
- 只有槳片從帽緣向外伸出或收回，整個頭頂模組不作垂直升降；不得額外畫出伸縮升降桅桿。這不等於模組永遠固定朝上：`直播相關8.png` 另有轉軸、滑軌與轉向背後的推進狀態。
- `直播相關7.png` 的 A／B 模組採低矮分層輪廓，B 的槳片伸出；不得僅依像素頭像把它放大成厚重、高圓頂的普通帽子。
- `直播相關8.png` 標有背部滑軌、活動蓋片、關閉狀態及約 90 度的轉向示意。依狀態表現結構，不自行增加大圓形接口，也不把原有軌道與蓋片全部抹成無結構球殼。此處是原圖機構核對，不新增能源、速度或其他性能數值。
- 尾巴末端另有球形部件，可放電作為攻擊手段。尾球、腹下起落架雙腳及頭頂螺旋槳是不同部件，不得互相混用，也不將尾球改成推進器。
- 尾球外殼會像花瓣一樣分瓣張開，張開後放電；此為創作者已確認的攻擊狀態。
- 臉部結合螢幕表情與相機機械眼睛。相機用於調整光線與焦距，平常開最大且不變化。
- 平常可愛、正常睜眼；吐槽時由螢幕呈現半眼或無言表情，不把相機光圈縮放當成表情變化。

### 能力與個性

- 保留策略核心的冷靜、理性、精準與毒舌，負責戰術推演、資料流駭入、邏輯除錯與高速運算。
- 平常經常吐槽、提醒恩雅。
- 面對作品反覆出錯時，會自言自語、反覆思考。
- 可以接受有道理的批評。
- 尾球放電攻擊為創作者新增確認的能力；射程、威力、作用對象與限制均未指定，不另行擴寫。

## 圖像製作規則

- **目前採用方式：不再生成人物，也不使用先前的生成角色圖。** 原始 PNG 使用逐位元相同的副本；GIF 只提取第一影格，沒有重繪、補畫或生成式處理。網站不自動播放 GIF。
- 網站採精細像素科幻方向：看得見像素邊緣，仍清楚保留眼鏡、金瞳和機械細節。此為畫法選擇，不改變角色比例與設定。
- 先前 2026-10-07 的局部授權：創作者允許兔子緹亞參考原始設定，使用圖片生成圖片。僅兔子形態可將指定的原始圖與機構示意圖傳入生成工具；不將此授權擴及恩雅或其他原始作品。此段保留歷史流程，不代表目前還要生圖。
- 先前恩雅與場景採「閱讀素材 → 整理文字 → 純文字生成」；未把其原圖或含有其原始形象的綜合設定圖傳入生成工具。原始資料繼續維持唯讀。
- 原圖、來源素材目錄與使用者示意圖維持唯讀，所有生成結果另存新檔；所用參考圖、提示詞與核對結果另記於本輪生成紀錄。
- 第一輪生成圖把兔耳誤寫為側翼，把收合雙腳誤寫為固定短筒，並將恩雅畫得過於冷峻。這些描述已失效，後續提示不得沿用。
- 尚未指定的構造資訊不以推測補成定案；這些空白不阻礙使用原始素材完成介紹網站。
