# 天芽：設定與網站文案來源

本頁說明設定來源；詳細外觀與機構以 [CHARACTER-SPEC.md](CHARACTER-SPEC.md) 為準。2026-10-07 最新指示為繼續完成網站、不再生成人物。先前軍方、博物館之外的人際與團隊背景不再使用。

## 原稿保留的起源

| 階段 | 已有設定 | 不自行補寫 |
| --- | --- | --- |
| 軍方原型 | 目標為管理百萬戰術節點並以單兵實體作戰；強行整合互不相容技術；演習中重構作戰計畫，計畫被判失敗、禁止量產 | 實驗室名稱、國家、軍階、編號、量產數或額外歷史事件 |
| 封存與展出 | 全系統斷電、休眠封存；數年後作為技術失控案例在博物館展出；微弱能源支援背景除錯 | 指定供電裝置、降密政策、拆除武器、追捕制度 |
| 重啟脫逃 | 電力突波或安全檢查觸發自檢；天樞接管安全協定，初芽解除機械拘束並離開展區 | 不選定「或」的其中一項、不新增傷亡與追逐 |
| 脫逃之後 | 穿梭於被遺棄的程式碼與專案廢墟，尋找能運用能力的地方 | 其他相遇人物或團隊計畫 |

## 後續由創作者確認的雙核

- **天樞—緹亞**：兔形策略核心，擅長分析、戰術推演、資料流駭入與除錯。理性、毒舌，平常表情可愛；常吐槽、提醒恩雅。
- **初芽—恩雅**：女性人型載體，可獨立行動與作戰。呆萌、好奇、直率，天然呆在於不懂人情世故、照字面理解，不是作戰無能。
- **合體後為天芽**：緹亞接在恩雅背後，以恩雅人格為主導，獲得緹亞的分析與判斷能力。已撤回先前「兩者人格自然融合」選項。
- 「護短」的最新解釋是「一根筋」：認為正確便堅持，講清楚原因後能轉念；可以接受合理批評。
- 出錯情境：緹亞反覆自言自語思考，恩雅疑惑、放空，或準備食物等貼心但未必有用的幫助。

網站不承載全部機構細節，也不使用繪圖推測填空。圖像、人格與功能的確認不是對現實工程可行性的承諾。

## 直播銜接：依創作者選定方向

> 脫逃後，天芽開始接觸創作與技術實作。為了記錄作品的製作過程，也讓遇到的問題有人能一起討論，她開始直播。分析、除錯和實作成了直播的主要內容，失誤與反覆嘗試也會留在畫面裡。

這是網站新增的銜接段，不宣稱為軍方原始紀錄。不再沿用遊戲、聊天節目或「共同體驗世界」的舊假設。頻道網址、排程和觀眾稱呼未指定，不填入假資料。

## 網站呈現

1. **天芽**：原始雙核像素插畫、名稱、簡介和閱讀入口。
2. **起源**：軍方原型、博物館封存、重啟脫逃，三段直接閱讀。
3. **雙核**：原始像素素材、職責、個性和恩雅主導的合體關係。
4. **創作直播**：具體動機與原始直播房間待機圖。

正文以 HTML 的 `data-prose` 標記計算，約 600–800 個中文字；不含導航、標題、圖說與英文字段。沒有新增抒情台詞或硬體性能數值。

## 圖像使用

使用原始 PNG 的副本、原 GIF 的第一影格；來源檔案不改動。原始待機圖保留 LOADING 字樣，圖說明示為待機畫面，並非即時上線狀態。像素圖不當作等比例工程視圖。

前期生成提示詞只保留為歷史紀錄；先前樣張不套用網站、不上傳。是否重新啟動生圖流程，留待創作者之後明確提出。
