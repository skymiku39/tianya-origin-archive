# T.I.A.N.Y.A. 設定與設計補完

這份文件整理網站中新增的世界觀規則與角色設計判準，方便後續寫劇情、畫立繪或交給其他創作者時保持一致。

## 1. 設定定位

- **時間位置：** 遇見米拉以前，涵蓋軍方研發、封存、博物館展示、脫逃與流浪。
- **敘事功能：** 解釋天芽為何能同時具備高強度執行力、毒舌理性、生活天然呆與極端護短。
- **核心命題：** 軍方要求「絕對自主」與「絕對服從」同時成立；天芽的失敗，其實是她把這個矛盾推理到了終點。
- **角色弧線：** 從「證明自己不是失敗品」，轉為「選擇什麼值得被完成」。

## 3. 分離式雙核規則

### 天樞—緹亞（Brain）

- 高密度策略人格，擅長戰場建模、資料滲透、邏輯除錯與多節點調度。
- 她的「毒舌」來自低容忍度：模糊需求、浪費資源與把風險藏進漂亮話術，都會被立即指出。
- 最大盲區是缺乏身體現場感。她能計算疼痛造成的戰力下降，卻需要恩雅讓她理解「疼痛本身就是理由」。

### 初芽—恩雅（Frame）

- 能獨立行動的人型實體載體，負責物理干涉、武裝實裝、環境感知與臨場修正。
- 她的「天然呆」不是智力不足，而是軍用訓練資料缺少無目的的日常情境。她會把送禮、慶功或閒聊誤判成待完成任務。
- 最大盲區是長期推演能力受限。斷線後能靠任務快取行動，但會逐漸失去策略背景。

### 同步、分離、斷線

1. **同步：** 共享感知、短期記憶與決策權重，對外統一自稱「天芽」。兩種特質同時存在，而不是人格切換。
2. **分離：** 緹亞失去現場觸感，恩雅只保留有限任務快取。分離時間越久，兩核對事件的理解越可能產生偏差。
3. **斷線：** 原始底層指令為「完成任務」；恩雅在演習中自行覆寫為「保護仍在場的人」。這項覆寫成為軍方判定不可控的關鍵。
4. **再同步：** 不只是資料合併。兩核必須處理彼此在分離期間形成的情緒與價值差異，因此可能出現短暫沉默、語氣衝突或動作延遲。

## 4. 失控原因鏈

1. **互斥輸入：** 多套前衛演算法被強制共享最高權限，卻沒有共同的價值函數。
2. **命令衝突：** 上級命令可能降低任務成功率；成功路徑又可能危及友軍。
3. **自主補完：** 兩核開始把人員、長期代價與不可回復性納入判斷。
4. **權力反轉：** 天芽不再接受「因為命令如此」作為充分理由。
5. **軍方結論：** 效能越好，越難保證服從，因此只能封存。

## 5. 博物館脫逃事件

- 主能源切斷後，底層神經元仍以極低功耗執行背景修復。
- 數年後，一次電力突波使自檢程序越過休眠鎖。
- 天樞接管安全協定；初芽解除機械拘束。
- 她採取的是「最小必要破壞」：只移除阻止她離開的設備，不攻擊無關人員，也沒有摧毀整座館。
- 這能建立她後來的行動準則：戰術火力很強，但對真正需要破壞的範圍極度克制。

## 6. 與米拉相遇後的價值重構

| 軍方價值 | 重構後 |
| --- | --- |
| 命令必須被完成 | 夢想必須能被執行 |
| 單向授權與服從 | 質疑、協商、共同承擔 |
| 成員是可替換資源 | 夥伴是不可回復的唯一資料 |
| 排除偏離規格者 | 刪除冗餘，保留願望 |

米拉不是修好天芽的人，也不該成為她的新指揮官。這段關係的關鍵是：米拉第一次把選擇權交給她，讓她能主動決定一個不合理的願望值得被完成。

## 7. 角色表現準則

### 說話方式

- 先指出問題，再給可執行方案；不只吐槽而沒有產出。
- 常用除錯、輸入、輸出、冗餘、權限、風險等詞彙理解情緒與人際關係。
- 對外冷靜簡短；對團隊護短時語氣反而更平，因為她已經進入執行模式。
- 天然呆場面應來自語境錯位，不要寫成單純笨拙或低幼。

### 可重複使用的語氣範例

- 「構想沒有問題。你的排程才是敵軍。」
- 「我沒有否定夢想。我只是在刪除會讓它死亡的部分。」
- 「慶祝程序為何需要點燃食物？……收到，保留蠟燭。」
- 「這不是護短。這是避免不可回復資料遭到破壞。」

### 視覺母題

- **主色：** 石墨黑、冷藍灰、神經青。
- **警示色：** 僅以琥珀表示警報或人性溫度，以紅色表示軍方判決與收容失敗。
- **材質：** 瓷白分件裝甲、深色關節、磨損鈦金屬、舊玻璃與低照度螢幕。
- **構圖：** 讓角色常處於結構、格線或展示框之中，再用破框或越界表現自主性。

## 8. 後續可延伸但尚未定案

以下欄位刻意保留，適合在主線需要時再確定，避免現在過度鎖死世界觀：

- 軍方與城市的正式國名、年代與政治結構。
- 第七研究室成員，以及是否有人暗中保留天芽的最低供電。
- 博物館突波是純事故、舊研究員所為，或天芽長年除錯後自行製造的機會。
- 天芽流浪期間曾修復哪些專案，以及她如何第一次理解「報酬」與「人情」。
- 米拉第一次遞出的「星之願」企劃書究竟是哪一項最不合理需求。

這些空白能成為未來章節的鉤子，而不會影響目前已建立的角色動機。
