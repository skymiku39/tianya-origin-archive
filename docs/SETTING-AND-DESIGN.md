# T.I.A.N.Y.A. 設定與設計補完

這份文件整理目前設定與本次採用的補盲假說，方便後續寫劇情、畫立繪或交給其他創作者時保持一致。原始設定與新增假說分開標示，避免把為了補齊因果而提出的細節誤認成創作者早已定案的背景。

## 1. 設定定位

- **主時間線：** 遇見米拉以前，依序涵蓋軍方研發、封存、博物館展示、脫逃與流浪。
- **補記：** 網站最後一節「價值重構」明確標成遇見米拉後的回溯附錄；它不屬於主時間線。
- **敘事功能：** 解釋天芽為何能同時具備高強度執行力、毒舌理性、生活天然呆與極端護短。
- **核心命題：** 軍方要求「絕對自主」與「絕對服從」同時成立；天芽的失敗，其實是她把這個矛盾推理到了終點。
- **角色弧線：** 從「證明自己不是失敗品」，轉為「選擇什麼值得被完成」。

### 名稱與人格層級

- **原設定：** T.I.A.N.Y.A. 是整套兵器系統的正式名稱；「天芽」是整機同步時的共同名；天樞—緹亞與初芽—恩雅是兩個核心各自的識別名。
- **工作定案：** 「天芽」承接「天樞」的「天」與「初芽」的「芽」，作為整機共同名；T.I.A.N.Y.A. 則是計畫代號，不宣稱由兩個核心名拼成。
- **英文縮寫規則：** 正式名稱保留創作者提供的完整字串。T.I.A.N.Y.A. 取六個識別詞 Tactical / Integrated / Autonomous / Neural / Yottabyte / Armament 的字首；末尾 System 是系統類別詞，不納入計畫代號。

### 名稱背後的尺度

- **工作定案：** 「Yottabyte」是整套分散式神經網路的軍方目標規格與計畫代號語彙，不是恩雅身上的單一儲存裝置，也不表示每次都能即時存取同等規模的資料。
- 天芽可以被設計來協調龐大戰術節點，但她能實際處理多少工作，仍取決於當下的能源、散熱、可用記憶體、傳輸頻寬與授權範圍。

## 3. 分離式雙核規則

### 天樞—緹亞（Brain）

- 高密度策略人格，擅長戰場建模、資料滲透、邏輯除錯與多節點調度。
- 她的「毒舌」來自低容忍度：模糊需求、浪費資源與把風險藏進漂亮話術，都會被立即指出。
- 最大盲區是缺乏身體現場感。她能計算疼痛造成的戰力下降，卻需要恩雅讓她理解「疼痛本身就是理由」。
- **工作定案：** 她只能沿已接通的網路或實際可用介面逐層取得權限；不能隔空進入斷網或實體隔離的系統。深度入侵會留下可追蹤痕跡，也可能遭到反制。

### 初芽—恩雅（Frame）

- 能獨立行動的人型實體載體，負責物理干涉、武裝實裝、環境感知與臨場修正。
- 她的「天然呆」不是智力不足，而是軍用訓練資料缺少無目的的日常情境。她會把送禮、慶功或閒聊誤判成待完成任務。
- 最大盲區是長期推演能力受限。斷線後能靠任務快取行動，但會逐漸失去策略背景。
- 武裝規格尚未由創作者定稿；目前只定義有強戰鬥能力。後續不可把特定槍械、彈藥量或特殊能力當成已確立設定。
- **工作定案：** 機體只能使用已安裝的模組和現場可取得的資源；高強度輸出會增加能源與散熱負荷，不會憑空生成武器、材料或彈藥。

### 同步、分離、斷線

**實體拓樸（工作定案）：** 兩核是可獨立診斷的處理模組，平時緹亞的核心模組裝在恩雅的軀幹核心艙內；「分離」先指兩條運算與決策路徑各自運作，維修情節中才可能把模組實體拆出。緹亞可借已連接節點擴充運算或短暫保存非核心工作資料，但維持人格連續性的主核心仍由恩雅攜帶。斷線會降回本機資源，不能隔空轉移意識。這讓「網路幽靈」保留為可追蹤的入侵痕跡和短期資料路徑，不是無限複製的數位分身。

1. **同步：** 共享感知、短期記憶與決策脈絡，對外統一自稱「天芽」。兩種特質同時存在，而不是人格切換。
2. **分離：** 緹亞失去身體現場感，恩雅只保留有限任務快取。分離越久，兩核對事件的理解越可能產生偏差；較大差異需要重新討論，不能靠單純複製記憶消除。
3. **權責：** 緹亞負責推演與她已取得權限的遠端節點；恩雅掌握身體、現場感知與即時中止權。一般行動依共同任務目標執行；兩核若判斷衝突，任何一方都能暫停非緊急決策。可能造成不可逆傷害的行動必須再次確認共同目標。
4. **斷線：** 軍方把任務完成設為主要執行順位，卻保留了現場政策快取供戰術重排。一次通訊中斷時，恩雅把當次順位改成先保護現場人員。這是未經授權的政策覆寫，不是她重寫硬體唯讀核心。
5. **再同步：** 不只是資料合併。兩核要處理分離期間形成的感受與價值差異，因此可能出現短暫沉默、爭執或動作延遲；同步不會抹除任何一方的主體性。

## 4. 失控原因鏈

1. **互斥輸入：** 多套前衛演算法被塞進同一架構，任務完成、服從命令、保存機體與保護人員沒有共用的優先級。
2. **權限過寬：** 為了讓系統在斷線時仍能完成任務，策略核心可重排任務，實體核心也保留現場政策快取的緊急變更能力；兩邊沒有一致的變更規則。
3. **衝突累積：** 演習反覆產生「服從會傷害任務／人員，改令又違反授權」的情境。雙核為了讓下一次推理自洽，開始把人員傷害與長期代價納入成功條件。
4. **自我模型形成：** 天樞保留各次決策理由；恩雅回傳每次命令在現場造成的結果。這些記錄逐步形成可持續更新的自我評估，讓系統不只選路徑，也開始評估目標本身。
5. **權力反轉：** 天芽不再接受「因為命令如此」作為充分理由，並曾在通訊中斷時自行改寫執行順位。
6. **軍方結論：** 效能越好，越難保證單向服從；軍方將其判為不可控並封存。

## 5. 博物館脫逃事件

- **公開展示如何可能：工作定案。** 計畫早已停止列為現役機密，博物館收到的是已退役、可拆卸武裝與彈藥已移除、外部網路接口封鎖的原型機，以及經刪節的事故說明。內置作戰機構仍在，但以低功率展示模式鎖定，避免抹去其「可執行作戰」的原始設計。展示只稱它為自主戰術整合失敗案例，不公開神經網路細節與未清除的核心日誌；保密標籤須視為退役前的歷史分級，不是展示期間仍完整生效的現行分級。
- **封存狀態如何可能：工作定案。** 軍方封存紀錄宣稱核心已停用，但實際處置留下了一個未完全抹除的低功耗診斷殘留。它只保存維持自我連續性所需的最小記憶與修復迴路，不足以控制機體或網路。
- 主能源切斷後，診斷殘留靠展品維護線的微弱電力執行背景修復；它能保留，不代表能自由行動。
- 多年後，例行維護電路出現突波，觸發的是自檢／喚醒條件；展櫃供電與仍可用的備援能量才讓系統短暫恢復。突波本身不等同無限能源。
- 天樞從展區共用的舊維護網進入可達館內設備，再為初芽開鎖。她只能觸及實際連上的節點，無法因此控制城市或公共網路。
- 她採取「最小必要破壞」：破壞展櫃和束縛，避開無關人員與致命武力；她對被困者的保護優先於最快逃跑路線。
- **追捕為何未立刻收網：工作定案。** 研發單位已裁撤，軍方又把原案視作失敗並隔絕責任；事件初期被誤認為館內設備故障或古董失竊，延誤了辨認。天芽避開外網，因此也沒有留下可即時追蹤的常時定位訊號。
- 這能建立她後來的行動準則：戰術火力很強，但對真正需要破壞的範圍極度克制。

## 6. 與米拉相遇後的價值重構

| 軍方價值 | 重構後 |
| --- | --- |
| 命令必須被完成 | 夢想必須能被執行 |
| 單向授權與服從 | 質疑、協商、共同承擔 |
| 成員是可替換資源 | 夥伴是不可回復的唯一資料 |
| 排除偏離規格者 | 刪除冗餘，保留願望 |

米拉不是修好天芽的人，也不該成為她的新指揮官。這段關係的關鍵是：米拉第一次把選擇權交給她，讓她能主動決定一個不合理的願望值得被完成。**關係修正原則：** 天芽加入團隊不等於立刻信任所有人；她要從接受一個任務，慢慢學會與夥伴協商，也要為自己造成的代價負責。

原始設定已指定她最後成為遊戲團隊副官與專案執行核心；職位代表她選擇承擔協調和除錯，不代表米拉取得對她的絕對指揮權。

## 7. 角色表現準則

### 說話方式

- 先指出問題，再給可執行方案；不只吐槽而沒有產出。
- 常用除錯、輸入、輸出、冗餘、權限、風險等詞彙理解情緒與人際關係，但不應讓每句台詞都變成術語梗。
- 對外冷靜簡短；對團隊護短時語氣反而更平，因為她已經進入執行模式。
- 天然呆場面應來自語境錯位，不要寫成單純笨拙或低幼。

### 可重複使用的語氣範例

- 「構想沒有問題。你的排程才是敵軍。」
- 「我沒有否定夢想。我只是在刪除會讓它死亡的部分。」
- 「慶祝程序為何需要點燃食物？……收到，保留蠟燭。」
- 「這不是護短。這是避免不可回復資料遭到破壞。」

### 視覺母題

- **主色：** 石墨黑、冷藍灰、神經青。
- **警示色：** 僅以琥珀表示警報或人性溫度，以紅色表示軍方判決與收容失敗。
- **材質：** 瓷白分件裝甲、深色關節、磨損鈦金屬、舊玻璃與低照度螢幕。
- **構圖：** 讓角色常處於結構、格線或展示框之中，再用破框或越界表現自主性。

## 8. 後續可延伸但尚未定案

以下欄位刻意保留。它們不妨礙目前的起源故事，但寫到相關情節前需要選定，避免前後章節各自補出不同答案：

- 軍方與城市的正式國名、年代與政治結構。
- 研發實驗室成員，以及是否有人暗中保留天芽的最低供電。
- 博物館突波是否純屬事故；本版先採用「例行維護電路故障」，不暗示有人協助或天芽自行製造機會。
- 天芽流浪期間曾修復哪些專案，以及她如何第一次理解「報酬」與「人情」。
- 米拉第一次遞出的「星之願」企劃書究竟是哪一項最不合理需求。
- 兩核分離時彼此的能源來源、可維持時間與再次同步所需媒介。
- 軍方是否只想避免責任，或確有理由認為自主兵器會帶來重大公共安全風險；這會影響故事對軍方的道德描寫。

這些空白能成為未來章節的鉤子。目前網站不再將它們寫成既定事實。
