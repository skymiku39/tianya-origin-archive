## 次要修正

1. **移除沒有來源的精確值。** 舊稿的 187 日、42 次演習、31 次偏航、93.7% 資料可信度及 99.2% 核心連線，都不是原設定資料。頁面已改成質性描述；將來若採用數字，需標明是軍方估值、殘存日誌或天芽自報，不能同時暗示客觀真值。
2. **解決縮寫少一個字母。** 完整名稱末尾的 System 為通用類別詞，不納入六字母計畫代號 T.I.A.N.Y.A.。天芽是雙核整機共同名，承接「天樞」和「初芽」的字意；代號不宣稱從「緹亞／恩雅」拼成。
3. **區分正式檔案與網站編目。** TYA-X01、試作代次、研究單位名稱與 OBSIDIAN–9 都是先前補寫的標籤，原設定沒有提供。頁面已把 TYA-X01 改標為本網站編目號，刪除虛構的單位與分級值，代次改成未定。
4. **避免虛構引文被誤認逐字檔案。** 舊稿附上無來源的「TYA-X01 最終評估會議，附件 7-B」，又將重建文案加引號。已改為非逐字的封存判定摘要，明示正式會議編號未定。
5. **限制博物館駭入範圍。** 天樞靠展區舊維護介面進入共用館內設備；她不能因此接管全館以外的城市網路。這也讓脫逃仰賴天樞的存取與恩雅的實體行動共同完成。
6. **交代克制與代價。** 脫逃採最小必要破壞；無關人員安全優先。過度出力會耗能、積熱，武裝必須已安裝或現場取得。具體武器型號仍屬待定，避免把創作補充誤作原設定。
7. **避免雙核分離後自動完美同步。** 離線期間的記憶和價值差異不會因複製資料消失；重新連線可能需要對齊、解釋甚至爭執。這為雙核關係提供持續的戲劇空間。
8. **避免米拉變成新指揮官。** 米拉提供提問和選擇，沒有替天芽下達新的人生命令。加入團隊不等於立即信任，天芽仍需學習協商和承擔自己改動計畫造成的後果；網站已明確寫出她選擇擔任遊戲團隊副官與專案執行核心。

## 後續創作檢查表

- 天樞入侵任何系統前，先交代接入方式、可取得的權限與可見風險。
- 天芽做高出力行動時，交代能源、散熱或時間上的代價。
- 雙核意見衝突時，交代分歧來自策略、現場感知或價值排序；不要讓其中一核無條件壓過另一核。
- 若要保留具體日期、測試次數、傷亡或效能百分比，給數字一個明確檔案來源並標出可信度。
- 任何寫在「遇見米拉以前」的內容，不使用她加入團隊後才取得的關係或知識；後續回望請標示成補記。
