# 直播介紹版：設定與設計調整

本版依創作者的回饋調整：先前的補完加入太多未確認設定。現在以原始起源與雙核特質為基礎，讓故事延伸到開始直播的原因。

## 本次調整

| 需求 | 實作 |
| --- | --- |
| 移除額外人際背景 | 網站與現行設定文件不再包含創作團隊相遇、團隊副官或相關專案的段落 |
| 收回過度補完 | 移除自訂軍方編號、核心安裝位置、斷線政策覆寫、降密與武裝拆除、維護供電、追捕延誤等自行擴寫的細則 |
| 接到直播 | 以「離開被動陳列，主動與人交流」連接原型機起源與直播動機 |
| 參考既有素材 | 使用提供目錄裡的像素插畫與直播待機畫面副本 |
| 遵守圖片流程 | 本次不生成圖片；若日後生成，採圖片整理成文字後再純文字生圖 |

## 設定編寫原則

- 原始背景與本次新增的直播文案，在設定文件中清楚標示來源。
- 不以「工作定案」把建議自動升格成創作者已確認的設定。
- 不增加未提供的數字、研究單位、國家制度、歷史事件或固定觀眾稱呼。
- 起源段保留原稿中的軍方判定，避免替軍方新增未指定的道德立場。
- 博物館重啟仍維持原稿中的「電力突波或安全檢查」，不選定事故原因。
- 圖像細節不等於世界觀證據；不把小型機械的外觀直接指定為某一核心或新角色。
- 頻道網址未提供時，頁面提供故事導覽，不建立假直播連結。

## 頁面設計

保留深色、科幻與檔案感，使用原有角色素材的薄荷綠和紫色讓視覺貼近直播形象。首頁直接介紹天芽，依序呈現角色、雙核、起源與直播動機。

起源以原生 details/summary 展開閱讀；雙核分頁可使用方向鍵、Home、End。啟動紀錄可按 Escape 關閉；頁尾提供短版自我介紹供複製。減少動態效果的瀏覽器設定會直接顯示啟動文字。

來源目錄只供讀取，網站使用獨立副本。舊版內容可透過 Git 歷史回看，不作現行設定。
