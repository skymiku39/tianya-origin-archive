# 像素原始素材版：設計與驗收

## 決策與範圍

依創作者最新指示「繼續做，不用生成人物」，停止角色樣張製作，網站改用原始像素插畫及原 GIF 的靜態影格。沒有生成新圖片，沒有把未核准的兔子構造上線。先前生成圖保留本機、排除 Git，提示詞留作歷史紀錄。

本版重新整理的核心不是增加世界觀，而是使已確認的設定能直接閱讀：

- 軍方原型 → 博物館封存 → 重啟脫逃 → 創作與技術實作直播。
- 天樞—緹亞為兔形策略核心；初芽—恩雅為人型載體。
- 合體以恩雅主導，不採用已撤回的「人格自然融合」。
- 恩雅可愛、好奇、照字面理解；「一根筋」不是不接受合理批評。
- 不使用額外相遇人物、遊戲直播、固定節目或假頻道網址。

## 視覺與互動

- 深藍灰背景、薄荷綠和紫色、硬邊像素裝飾，搭配中文黑體。不是將整頁文字像素化。
- 首頁圖文分開，原始 16:9 插畫完整展示；不使用滿版裁切，也不把文字蓋在臉上。
- 起源直接展開三段故事，不設彈窗或折疊。
- 兩核並排、手機上下排列；圖像為原始像素形象，不是等比例工程圖。
- 原始待機房間圖收尾，保留圖中 LOADING 並明示待機圖，不偽裝即時上線。
- 沒有自動播放、視差、浮動角色、內容進場隱藏或複製按鈕。只有章節標示以 JavaScript 增強。
- 保留原有 `#top`、`#dossier`、`#history`、`#architecture`、`#streaming`。
- 更正分享圖片為實際存在的原始像素插畫；CSS/JS 帶版本參數，避免新 HTML 混用舊快取。

此為 Chromium 瀏覽器的尺寸與功能驗收，不代表已在實體 iOS/Safari 裝置測試。分享 metadata 已驗證，第三方平台既有快取可能延遲更新。

## 維護界線

頻道、排程尚未提供，不補佔位連結。緹亞耳側部件的詳細用途、尾球射程、工作尺寸等未細訂項目，不以推測補成定案，也不阻礙此版網站上線。圖像中的背景道具不能新增為角色能力。

GitHub Pages 沿用 main 分支根目錄，不增加公開 API 或後端。詳見 README、CHARACTER-SPEC 與 source-assets.json。
