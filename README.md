# T.I.A.N.Y.A. 原型機解密檔案

一個以「軍方解密檔案 × 科幻角色設定集」為視覺方向的單頁敘事網站，記錄天芽在遇見米拉之前，從軍方原型機、博物館展示品到脫逃者的歷史。

## 預覽

直接開啟 `index.html`，或在專案目錄執行任意靜態伺服器：

```powershell
npx serve .
```

## 內容結構

- 原型機軍方檔案與失敗判定
- 天樞—緹亞 / 初芽—恩雅的雙核架構
- 雙核同步、分離與斷線規則
- 實驗室、博物館、脫逃、資料荒原四階段沿革
- 遇見米拉後的核心價值重構
- 可互動的系統自檢、雙核切換與歷史紀錄
